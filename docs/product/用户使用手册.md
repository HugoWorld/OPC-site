# 用户使用手册

- 适用版本：OPC-site v40（2026-11-12）
- 适用读者：站点经营者（管理员）；访客浏览部分对所有人适用
- 配套文档：[部署与运营注意事项](./部署与运营注意事项.md)

## 1. 这套系统是什么

OPC-site 是“个人专业门户 + 可视化运营工作台”：

- **访客站**：展示能力、产品、案例、文章、分享与联系方式；
- **运营工作台**：不写代码，改内容、看预览、点发布，访客站随即更新；
- **数据后端**：飞书多维表格（Base）保存内容，服务器保存一份已发布快照。

工作台地址通常是 `http://服务器IP:8081`，访客站是 `http://服务器IP:8080`；绑定域名后以实际域名为准。

## 2. 第一次登录

### 2.1 飞书扫码（推荐）

1. 打开工作台地址，进入登录页；
2. 点「使用飞书账号登录」，用手机飞书扫码；
3. 授权后回到工作台。

扫码能用的前提：

- 飞书账号属于**企业/团队租户**，不是个人版账号；
- 飞书后台已创建“企业自建应用”，并开启网页授权；
- 你的 `open_id` 已加入服务器 `.env` 的 `ADMIN_OPEN_IDS` 白名单；
- 应用可见范围包含你本人；
- 回调地址与访问域名完全一致。

> 个人飞书账号、未加入企业租户的账号，通常无法完成企业自建应用授权，会看到“无权限”或 `21001`。这时请改用账号密码入口，或让企业管理员把你加入租户和应用可见范围。

### 2.2 账号密码（备用）

登录页可切换到「账号密码」。账号密码来自服务器 `.env`：

```ini
ADMIN_LOGIN_USER=admin
ADMIN_LOGIN_PASSWORD=...
```

`install.sh` 首次安装会生成密码并在安装结束打印一次。密码只保存在服务器，不要发到群里、不要提交到 Git。

### 2.3 登录后看到什么

- 顶部：站点名、草稿状态、上次发布时间、查看站点、账号；
- 左栏：12 个模块；
- 中栏：当前模块的编辑区；
- 右栏：访客站实时预览（草稿状态，不是工作台本身）。

## 3. 工作台布局

| 区域 | 用途 |
|---|---|
| 顶栏 | 草稿状态、上次发布时间、查看站点前台、退出登录 |
| 左栏 | 总览、站点信息、首页内容、产品管理、分享管理、能力模块、文章与案例、方法与 FAQ、关于我、页面管理、主题与排版、发布与导出 |
| 中栏 | 分组折叠编辑区；改动自动保存为草稿 |
| 右栏 | 实时预览；可平铺全屏、新标签打开、定位当前组 |

顶部状态条只有一处，含义如下：

- `草稿与站点一致 · 上次发布 HH:MM:SS`：没有未发布改动；
- `草稿已自动保存 · HH:MM:SS`：有改动，尚未发布。

## 4. 内容编辑

### 4.1 十二个模块

| 模块 | 主要维护内容 |
|---|---|
| 总览 | 初始化状态、统计、快速入口、站点预览 |
| 站点信息 | 站点名、副标题、导航、页脚、社交链接 |
| 首页内容 | 首屏、数字条、卖点、受众、区块顺序、评价 |
| 产品管理 | 产品卡、上下架、排序、封面图、轮播间隔 |
| 分享管理 | 分享分组、标题、说明、外链 |
| 能力模块 | 方案字段、正文、排序、上下架 |
| 文章与案例 | 文章增删改、分类、正文、关联模块 |
| 方法与 FAQ | 交付步骤、价格、边界、常见问题 |
| 关于我 | 导语、履历、工作原则、不承诺清单 |
| 页面管理 | 自定义页面、区块编排、设为首页 |
| 主题与排版 | 强调色、密度、品牌形象、恢复首页 |
| 发布与导出 | 发布、导出 YAML/TS、重置草稿/已发布 |

### 4.2 编辑与自动保存

- 直接改输入框、文本域、下拉框；
- 改动约 500ms 后自动写入浏览器草稿，没有单独「保存」按钮；
- 关闭页面不会丢草稿，但草稿只存在当前浏览器；
- 换电脑、换浏览器、清空浏览器数据，草稿不会自动跟过去。

### 4.3 列表操作

- 「添加一项」在列表末尾新增；
- 「删除」会先弹出确认，取消不会改草稿；
- 「上移 / 下移」调整顺序；
- 页面区块删除、页面删除、设为首页、重新配置向导也都有确认框。

### 4.4 图片

- 产品、分享、头像等位置支持上传图片；
- 上传后图片以 data URL 写入草稿，预览立即可见；
- 「清除」会移除当前图片；
- 图片越大，草稿体积越大，建议先压缩到合理尺寸再上传。

## 5. 预览

- 右栏默认是移动端宽度预览，内容来自**草稿**；
- 「平铺预览」把预览铺满右栏，按 `Esc` 或「缩回预览」返回；
- 「新标签」在新窗口打开完整预览，地址带 `?preview=1`；
- 「定位当前组」会滚动到正在编辑的区块，并出现橙色高亮框和提示条「已定位到当前编辑组」；
- 预览未加载完成时，会提示「预览尚未加载完成，请稍后重试」。

如果点击定位没有高亮，先确认预览已加载、当前模块有对应区块，再重试。

## 6. 发布

### 6.1 发布前

发布是对访客可见的变更。点「发布」后会弹出确认框，说明会立即更新前台并覆盖上一版本。

- 取消：不发布，草稿保留；
- 确认：执行发布。

### 6.2 两种发布方式

- **发布全部**：整份草稿写入 Base，并生成本机快照；
- **发布本模块**：只发布当前模块对应内容。

发布成功后，访客站刷新即可看到新内容。

### 6.3 发布失败

发布失败不会切换当前快照，访客继续看到上一版完整内容。先看工作台提示和 `./hugow logs`，常见原因是 Base 缺表、应用没有加入 Base、飞书凭据/租户不对。

### 6.4 重置

- 重置草稿：清除本地未发布改动；
- 重置已发布：把已发布内容恢复为出厂内容；
- 两者都有二次确认，执行前先备份。

## 7. 页面管理

### 7.1 新建页面

- **模板**：SaaS 产品首页、咨询服务页、工作室个人品牌页；
- **导入 JSON**：粘贴模板导出的页面 JSON，格式错误会提示「JSON 解析失败，请检查格式。」。

### 7.2 区块

页面由首屏、数字条、卡片、文本、问答、时间线、行动号召、多栏、图片、价格、好评墙等区块组成。可增删、排序、编辑字段。

### 7.3 设为首页

「设为首页」会改 `theme.homePageSlug`，发布后站点根路径渲染该页面。操作前会确认；想还原时在「主题与排版」点「恢复内置首页」。

### 7.4 在预览中打开

这个按钮实际是**把右侧预览切到该页面**，不会新开浏览器标签。想看完整新窗口，请用预览工具条的「新标签」。

## 8. 主题与排版

- 强调色、副色：改变主色与按钮色；
- 密度：紧凑 / 标准 / 宽松；
- 品牌形象：头像、名称、标识；
- 「应用该主题」会覆盖首页人设、数字条、能力模块、文章样例、演示卡、配色与密度，操作前有确认。

主题只改变视觉与排版，不改页面结构。

## 9. 导出与迁移

在「发布与导出」可以：

- 导出 YAML：便于人工审阅；
- 导出 TS：可替换源码中的数据文件；
- 导出迁移包：用于备份或迁移到另一台服务器。

导出文件可能包含站点内容与图片 data URL，不要公开发布包含个人信息或联系方式的导出文件。

## 10. 退出与会话

- 点右上角退出，回到登录页；
- 退出只清登录状态，不删草稿和已发布内容；
- 会话默认 12 小时，过期重新登录；
- 工作台先向服务器验证登录态，再渲染内容；本地缓存不能冒充登录。

## 11. 常见问题

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 扫码后提示无权限 | `open_id` 不在白名单，或应用可见范围不包含你 | 让管理员把你加入 `ADMIN_OPEN_IDS` 和应用可见范围 |
| 扫码报 `21001` | 账号不是企业租户，或平台策略拒绝应用换 token | 换企业账号/企业租户；临时用账号密码 |
| 扫码报 `20029` | 回调地址与访问域名不一致 | 飞书后台、`.env`、实际域名三处统一 |
| 扫码页 4401/请求无效 | 二维码授权地址失效或应用配置不完整 | 改用账号密码；检查应用网页授权 |
| 登录后马上掉线 | HTTPS 下 `COOKIE_SECURE=false`，或 HTTP 下为 `true` | 正式 HTTPS 设 `true`，本地 HTTP 设 `false` |
| 发布报 `TABLE_NOT_FOUND` | Base 缺表或表名不一致 | 核对 12 个英文表名；应用加入 Base |
| 发布后前台没变 | 只改了草稿没发布，或缓存 | 点发布并确认；刷新访客站 |
| 工作台打不开 502 | 端口/安全组/容器未启动 | 放行 8080/8081；`./hugow status`、`./hugow logs` |
| 预览是工作台不是访客站 | 预览地址被管理路由兜底 | 使用 `/preview/#/...?preview=1`，不要用 `#/admin` 当预览 |

## 12. 内容与合规

编辑文案时避免承诺性、绝对化表述，例如：保证、一定、100%、零风险、降本 X%、提效 X 倍、中标率、唯一、领先、首个；也不要承诺流量、排名、线索数量或模型准确率。

站点中的案例、证言、人物形象如为演示素材，应明确标注，不冒充真实客户或真实业绩。

## 13. 安全提醒

- 不把 `.env`、App Secret、Base access token、管理员密码、open_id 白名单发到公开仓库或群聊；
- 工作台账号只给站点经营者，离职/换人后立即改密码、移除白名单；
- 定期 `./hugow backup`，备份文件包含站点内容，妥善保管；
- 公开仓库只放示例占位符，真实凭据只放服务器 `.env`。
